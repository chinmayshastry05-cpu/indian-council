# Verdict template

The canonical template is the STEP 8 section list in [SKILL.md](../SKILL.md). Minimal skeleton:

```
## Council Verdict
### Problem
### Council Composition   (panel, 1.5x domain seat, Chairman: Krishna)
### Chairman note
### Acceptable Compromises
### Kill Criteria         (If X observed by DATE, the verdict is invalidated and we should Y)
### Concrete Next Step    (exactly one: verb object by date)
### Unresolved Questions  (what the council does NOT know)
### Recommended Next Steps
### Consensus & Agreement
### Vote Tally            (option, weight, backers with confidence; threshold 2/3)
### Key Insights by Member
### Points of Disagreement
### Minority Report
### Follow-Up
```
